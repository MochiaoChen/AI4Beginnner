## 🚀 如何使用

1. 从「[快速上手](notes/getting-started/README.zh.md)」开始
2. 学习「[基础概念](notes/fundamentals/README.zh.md)」
3. 查阅「[学习资源](notes/resources/README.zh.md)」获取更深入的资料
4. 使用「[模板](templates/README.md)」来整理自己的笔记
