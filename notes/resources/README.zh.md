## 🏃‍♀️ 学习路径建议

### 完全新手
1. 完成我们的「[快速上手](../getting-started/README.zh.md)」

3. 用 Teachable Machine 训练第一个小模型

5. 体验 Google AI Experiments

### 进阶学习者

2. 做 Kaggle Learn 微课程
3. 加入一个线上社区
4. 动手做一个简单项目
5. 学习 AI 伦理与偏见

### 未来从业者
1. 夯实统计与数学基础
2. 学习 Python 基础
3. 系统学习 Andrew Ng 机器学习课程
4. 做一些实战项目
5. 参与开源 AI 项目

## 🔍 如何评估资源

选择资料时关注：
- **解释清晰**，避免过多术语
- **可视化**（图表、动画、示例）
- **动手练习** 的机会
- **内容更新**（AI 发展很快）
- **口碑评价** 来自其他学习者

## 📝 学习建议

- **先概念后代码**：先理解，再实现
- **多渠道学习**：不同解释能相互补强
- **讲给别人听**：检验自己是否真正理解
- **保持好奇心**：多问“为什么/怎么做”
- **耐心**：AI 概念需要时间消化
